# DSH 多角色投研流水线 `invest_run` 使用指南

> 适用于 DSH（DeepSeek Harness）动态插件 `invt-11`，当前版本 **invest-run-v6.1**（pkg-19）。
> 更新日期：2026-08-16

---

## 1. 这是什么

`invest_run` 是在 DSH 会话中运行的多角色投研流水线工具：模拟 Dify 的多 Agent 协同，由 **4 个角色子代理按顺序接力**，每个角色使用自己的 Tushare 账户实时拉取 A 股数据，逐层产出分析，最终给出综合投资建议。

```
你（主对话）
  └─ invest_run 工具
       ├─ ① 选股分析师      （全市场扫描 / 指定个股分析，产出候选名单+交易计划）
       ├─ ② 市场重点消息获取师（消息面收集+可信度核验）
       ├─ ③ 股票深度分析师    （六维诊断+目标价+止损方案）
       └─ ④ 总判断师         （综合前三份产出，输出最终决策建议）
```

每阶段产出会**自动传递给下一阶段**（总判断师能看到全部三份上游材料），任一阶段失败会自动重试 1 次。

---

## 2. 快速开始

**不需要任何特殊操作**——直接像平时一样向 DSH 提问即可（可含**多只股票**做对比，如"对比分析长江电力和中国平安哪只更值得买入"），我会自动调用 `invest_run`：

```
请对长江电力(600900.SH)做完整投研分析，给出最终投资建议
```

也可以更明确地指定模式：

```
invest_run 模式=选股，帮我扫描今天值得关注的股票
对宁德时代做深度分析
帮我收集一下市场最近的重大消息
```

## 3. 运行模式（mode 参数）

| mode | 执行阶段 | 耗时参考 | 适用场景 |
|---|---|---|---|
| `选股` | ① 选股分析师 | 1–3 分钟（缓存命中时 <1 分钟） | 全市场扫描 / 个股交易计划 |
| `消息` | ② 市场消息获取师 | 2–4 分钟 | 收集目标标的消息面 |
| `深度分析` | ① → ③ | 4–6 分钟 | 个股深度诊断（六维+目标价+止损） |
| `总判断` | ①∥② → ③ → ④ | 6–8 分钟 | 完整流水线 |
| `all`（默认） | ①∥② → ③ → ④ | 6–8 分钟 | **完整投研+最终建议** |

> ①选股与②消息**并行执行**（节省 2-3 分钟）；不指定 mode 时默认 `all`；耗时视网络与接口状态浮动，阶段失败自动重试会增加时间。**追问**：说"接着上次对 XX 的分析继续/对比 YY"即可，我会自动带上上次结论（context 记忆）。

## 4. 四个角色职责

| # | 角色 | 核心职责 | 关键产出 |
|---|---|---|---|
| ① | **选股分析师**（CherryClaw） | 全市场海选：三层过滤（金叉/量比/收红）、涨停回马枪、龙头首板策略；前置硬过滤（排除 688/300/301/ST/次新/低成交额） | 候选股票表（评分/评级/买入区间/止损/目标/仓位）、市场情绪、风险提示 |
| ② | **市场重点消息获取师** | 围绕目标标的/行业收集近期重要消息，只收集不做判断 | 消息表（时间/来源/摘要/影响方向）、要点总结、可信度说明 |
| ③ | **股票深度分析师** | 蜡烛图预警检查 → 六维诊断（K线/均线/量价/指标/资金/板块）→ 财务估值 → L1-L4 目标价 → 止损方案 → 综合评分 | 深度分析报告（多空理由各 3 条） |
| ④ | **总判断师** | 综合三份上游产出，不采集新数据 | 综合投资建议（总体判断/个股建议/操作建议/风险/免责声明） |

## 5. 数据来源与质量保障

**数据通道**：每个阶段子代理通过自己的 `pwsh` 工具调用 **Tushare Pro REST API** 实时取数（token 见第 8 节）。取数请求强制合并（一个脚本多接口），控制调用次数。

**两条铁律（防错机制）**：

1. **日期锚定铁律**：禁止用模型自身的时间概念判断"今天/最近"。所有阶段先用 `index_daily(000001.SH, end_date=年末)` 取返回记录中**最大 trade_date** 作为真实最新交易日；`trade_cal` 含未来日期不可作锚点。→ 解决"价格/日期错位"问题。

2. **数据覆盖铁律**：分析对象必须实际取到真实行情后才能给出具体价格；取数失败或接口无权限时**如实标注**，严禁编造数字；接口报错信息必须贴出。→ 解决"价格编造"问题。

**可信度标记**（报告中可能出现的标注）：
- `[接口无权限]` / `[接口超限]` — Tushare 接口权限或频率限制（见第 9 节）
- `[模型知识，可能滞后]` — 取数失败时用模型知识补充的条目
- `[未经公告原文核验]` / `[未经实时验证]` — 网络检索/推导数据，未核实原文

**独立核查**：子代理不盲从上游——曾自动发现并修正上游用错的接口字段（`limit_type`→`limit`）、修正资金流口径，属于正常现象。

## 6. 结果展示（GUI 卡片）

`invest_run` 调用在聊天区显示**专属工具卡片**（非默认 JSON 行）：

- **标题**：`投研流水线 · <模式名>`
- **阶段徽章**：每个角色一个，绿色=成功（含耗时）、红色=失败
- **运行中**：显示"子代理运行中…"
- **点击卡片头部**：展开 / 收起
  - 展开后显示 **SVG 图表图片**（若有）和**完整阶段报告**（可滚动）

图表图片由 Host 端 `chart-content` RPC 按需加载（路径白名单 `.dsh-invest/charts/*.svg`），无需手动打开文件。

---

## 7. 图表

- 生成目录：`E:\Dsh_WorkSapce\Dify_Agents\.dsh-invest\charts\`
- 格式：SVG（Agent 手写，折线/柱状/饼图/蜡烛图等）
- 命名：`<代码>_<内容>.svg`，如 `601318_price_15d.svg`、`300750_structure.svg`
- 查看方式：① 对话卡片内联显示；② 用 read 工具或右侧文件面板打开；③ 资源管理器直接打开（浏览器可渲染 SVG）
- 提示词要求报告正文提及图表时必须写完整绝对路径，否则无法被卡片收集展示

## 8. 配置文件

| 文件 | 用途 | 备注 |
|---|---|---|
| `E:\Dsh_WorkSapce\Dify_Agents\.dsh-invest\tushare.token` | Tushare API token | 明文单行文本；配置化不入插件代码 |
| `E:\Dsh_WorkSapce\Dify_Agents\.dsh-invest\charts\` | 图表工作区 | 子代理生成的 SVG 图表（内部工作区，勿手动整理） |
| `E:\Dsh_WorkSapce\Dify_Agents\.dsh-invest\cache\` | 行情缓存目录 | 交易日锚点 + 行情响应缓存（当日有效，命中标 [缓存命中]） |
| `E:\Dsh_WorkSapce\Dify_Agents\.dsh-invest\reports\` | 内部报告归档 | 每轮完整报告（含推理过程） |
| **`E:\Dsh_WorkSapce\Dify_Agents\invest-outputs\`** | **对外统一输出** | **每轮分析一个子目录 `<时间戳>_<问题关键词>\`，内含 `报告.md`（完整报告+推理）与 `图表\`（本轮全部 SVG 图表副本）。查看历史分析报告和图片统一到这里** |

**替换为自己的 token**：登录 [tushare.pro](https://tushare.pro) 个人中心复制 token，用文本编辑器覆写 `tushare.token` 文件内容（保留换行即可，读取时自动去除）即可生效，无需改插件代码。

## 9. 性能与成本参考

- 全流程（all）：**约 7–10 分钟**，4 个 spawn 子代理（每阶段最多 2 次尝试）
- 单阶段：选股约 80–180s、消息约 130–140s、深度约 110–200s、总判断约 20s
- 效率纪律：接口调用有次数上限（行情类每股各 1 次、指数情绪各 1 次、财务合计 1 次），输出压缩 ≤2500 字/阶段

---

## 10. 已知限制（重要）

1. **Tushare 积分限制**：`news`、`anns_d`（公告）、`research_report`（研报）等接口返回 `40203 无权限`，是**账号积分等级不足**（非系统故障）；消息阶段会自动改用网络检索并标注。
2. **`major_news` 频率限制**：每天 40 次，用尽后当日返回超限。
3. **`limit_list_d` 字段**：涨停/跌停分类字段在不同权限下解析可能异常，Agent 会如实标注"涨停家数未能精确统计"。
4. **动态插件生命周期**：插件定义在当前 DSH 进程内，**进程重启后需要重新加载**。插件源码已打包固化：GitHub 仓库 **https://github.com/Pikapiku09/dsh-invest-plugin**（`dist/invest-run.host.js` 与 `dist/invest-run.client.js` 可直接用于重新加载），或重启后说"继续投研任务"由我重新加载。
5. **数据时点**：所有分析基于真实最新交易日收盘数据（报告会标注日期），非实时盘中。

## 11. 常见问题 FAQ

| 问题 | 解答 |
|---|---|
| 给出的价格和日期看起来不对？ | 正常情况不会：有日期锚定+数据覆盖铁律。若怀疑，看报告首行的"数据基准：真实最新交易日 XXXX-XX-XX"，如无此标注或标注异常，指出具体数字让我复核 |
| 图表没显示？ | ① 展开卡片（点击头部）；② 若报告只写了文件名没写完整路径，该图不会被收集（v6.1 已修复提示词）；③ 确认 `.dsh-invest\charts\` 下文件存在 |
| 提示"接口无权限"？ | Tushare 积分不足，属账号限制；可升级积分或接受如实标注 |
| 运行太慢？ | 全流程 7–10 分钟属正常；可改用 `选股` / `深度分析` 等短模式 |
| 想换标的再分析？ | 直接说"再分析一下 601318.SH 的深度"即可（新调用）；若要对比，把上次结论贴出来让我综合 |
| 阶段失败了？ | 工具会自动重试 1 次；若仍失败会在徽章显示红色"失败"并附错误信息，可让我重跑该模式 |
