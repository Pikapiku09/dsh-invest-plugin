# 开仓前强制 Checklist（v1.1）

> 用途：把"止损、仓位、频率、心理"四条铁律变成每次开仓前**不可跳过的闸门**。
> 铁则：任何一只票，Checklist 任一栏为"拒绝"→ **禁止买入**，当天不许以任何理由手动买入。
>
> **v1.1 更新**：本闸门已内置进 `dsh-invest-plugin` 投研流水线——「选股分析师（候选硬约束）/ 股票深度分析师 / 总判断师」三个角色在给出任何"建议买入/加仓"结论前，必须输出完整 Checklist 并过闸（任一栏"拒绝"→ 结论强制为"拒绝买入"）。使用 invest_run 时自动生效，无需手动粘贴。下方 Part 1 提示词保留，供你自己维护的其他 Agent 使用。

---

## Part 1：Agent 端强制输出（粘贴进你的"选股 Agent"和"股票深度分析 Agent"的 system prompt 末尾）

```
【强制规则】只要问题涉及「是否买入 / 是否加仓 / 值不值得买」类决策，无论你的最终结论是买入还是拒绝，你都必须**在结论之前**输出完整的"开仓强制Checklist"（8 项逐项输出）。
任一项目不通过（标记为"拒绝"），最终结论必须为"拒绝买入"，并说明原因。
即使结论为不买入，也要在对应项目上标记「拒绝」+原因；拒绝必须明确，禁止含糊跳过。
禁止跳步：没有输出完整 Checklist 的买入建议一律无效，直接视为不合格输出。

【开仓强制Checklist 输出格式】

1. 仓位预算：本票拟投入 ____ 元；账户总资产 ____ 元；占比 ____%（上限25%）→ 通过 / 拒绝
2. 板块集中：同板块现有 ____% + 本票 ____% = ____%（上限40%）→ 通过 / 拒绝
3. 止损预设：止损价 ____（=成本×92% 或 10日线）；触发条件 ____ → 必须给出
4. 止盈预设：目标价 ____；移动止盈规则（如盈利回撤至+3%或破10日线离场）____ → 必须给出
5. 交易频率：本月该票已交易 ____ 次（上限3）；近3笔结果 ____（连亏3笔=强制停手一个月）→ 通过 / 拒绝
6. 追高检查：现价距10日线乖离 ____%；距近期高点 ____%；乖离>8%视为追高 → 通过 / 拒绝
7. 基本面核验：买入逻辑 ____；估值位置 ____；催化剂 / 消息面 ____；风险点 ____
8. 心理门禁：用户今日是否存在"必须赚 / 报复 / 焦虑"信号 → 通过 / 拒绝

最终结论：买入 / 拒绝买入（原因：____）
止损价与止盈价已确认；下单时必须同时挂好止损条件单。
```

（注：账户总资产、现有持仓、本月交易次数等账户数据，由用户在对话中提供最新持仓快照，Agent 据此计算，不凭空假设。）

## Part 2：人工下单前 10 秒确认单（贴屏幕旁）

- [ ] **止损条件单挂好了吗**（成本−8% 或破 10 日线）？——没有就点"卖出/取消"，**不许买入**
- [ ] 单票 ≤ 25%？同板块 ≤ 40%？
- [ ] 本月这只票 ≤ 3 次？没有连亏 3 笔？
- [ ] 不是追高？（乖离 10 日线 > 8% 默认拒绝）
- [ ] 这笔钱来自交易账户，**不是**生活账户（包/车/应急金）？
- [ ] 今天没有"必须赚"的情绪？

**全打勾 → 买。任何一格没打勾 → 关掉软件，去干别的。**

---

## Part 3：怎么接进你的 Agent 流程

1. **粘贴**：把 Part 1 的强制规则粘进"选股 Agent"和"股票深度分析 Agent"的 system prompt 末尾（或作为工作流最后一步的固定提示词）。
2. **喂数据**：每次想开仓，把最新持仓快照（像你发我的：总资产 / 仓位 / 持仓明细 / 当日盈亏）贴给 Agent。
3. **看结论**：Agent 输出 Checklist 后，你只需要看两处——**止损价是多少**、**最终结论是买入还是拒绝**。
4. **下单**：结论为"买入" → **同时挂买入单 + 止损条件单**（两步合一，不许分开下单）。
5. **拒绝即闭嘴**：结论为"拒绝" → 当天不许以任何理由手动买入该票。

## 附：一次完整示例（填空示范）

> 假设账户总资产 153,619 元，想买某票 30,000 元，半导体板块现有 37.6%……

```
1. 仓位预算：拟投入 30,000 元；总资产 153,619 元；占比 19.5%（≤25%）→ 通过
2. 板块集中：半导体现有 37.6% + 本票 19.5% = 57.1%（>40%）→ 拒绝
最终结论：拒绝买入（原因：同板块合计将超 40%）
```

**只此一条就拒绝——这就是 Checklist 存在的意义：在你最上头的时候，替你做那个理性的决定。**
