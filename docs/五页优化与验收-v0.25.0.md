# 五页优化与修复报告 v0.25.0

## 一、概览页

**问题**：统计卡不可点击、最近运行/结论不直观、无法快速了解上一次分析哪只股票及结论。

**方案**：
- 四张统计卡改为可点击按钮，分别跳转到运行记录/结论区/标的档案/归档报告。
- 新增"上次分析"主卡：自动取最新有报告的运行，显示标的名称+代码、问题、时间、耗时、立场、目标/止损、核心论据，可一键阅读报告或进入档案。
- 新增"最新观点分布"区：每只股票只保留最新一条结论，以卡片形式展示立场、论据、目标/止损，点击进入档案。
- 最近运行卡片增加标的名称+代码、立场标签。
- 最近结论表增加股票名、失效条件短摘要，整行可点击进入档案。

## 二、标的档案

**问题**：点击"焦点科技"展示"东方电缆"内容。

**根因**：索引构建器将报告正文里出现的所有股票代码（因注入持仓账本而包含多个）都套用了同一份结论，导致结论错绑。

**方案**：
- 索引优先采用任务问题中的代码和结构化结论的真实 code，报告正文出现的其他代码不再自动作为研究对象。
- 结构化日志与关键词回填去重，保留更可靠来源。
- ETF 代码（510500、159xxx）纳入索引。
- 前端档案按当前 code 二次过滤，防止异步残留。
- 新增 Python 归因回归测试（tools/test_index_store.py）。

## 三、一键任务

**问题**：报告图表加载失败（顶部失败底部正常）、报告含思考内容、右上角运行状态无法快速跳转。

**根因**：
1. Markdown 渲染器在提取反引号代码段之前将图表路径替换成图表 token，导致反引号内路径无法渲染为图片。
2. 归档器主动将 reasoning 写入报告。
3. 运行徽标只导航到任务页，未滚动到底部。

**方案**：
- 渲染器增加反引号图表路径识别，路径去重，失败后可重试（不再永久缓存失败 Promise）。
- 归档不再写入 reasoning；旧报告在阅读时兼容剔除推理段。
- 运行徽标点击后导航到任务页并滚动到最新任务。
- 任务列表 API 返回报告路径，避免前端无法找到报告入口。
- stock-quick 模板：明确"300 字结论不包含图表，图表照常生成"。

## 四、模型设置

**问题**：角色路由是自由输入框，难以调整。

**方案**：
- 新增 /api/model-settings 返回 modelOptions（从 llm.listProviders/listModels 获取真实模型目录）。
- 角色路由改为模型下拉框 + 推理强度下拉框（inherit/low/medium/high/max）。
- 保留当前自定义值为"当前自定义"选项。
- 改动路由时保留备选链后缀，不静默丢弃。

## 五、持仓工作区

**问题**：截图导入 Failed to fetch；账户总资产/可用资金不显示；手动新增无法输入中文。

**根因**：
1. 请求体上限 64KB，截图 base64 超过后连接中断，前端显示 Failed to fetch。
2. 账本字段 cash 与前端读取的 available_cash 不一致，导致显示为空。
3. 整页 render 在 IME 组合输入期间触发，打断中文输入。

**方案**：
- 请求体上限：常规 1MB，持仓导入 16MB；超限返回明确错误而非连接中断。
- 服务端截图压缩兜底（tools/compress_image.py）：>350KB 的图片经 PIL 缩放至长边<=1600px、JPEG 质量 86 压缩后再交给视觉模型。
- 前端上传前也执行压缩（canvas -> JPEG），支持浏览器环境。
- 账户字段兼容 total_asset/totalAsset/cash/available_cash/availableCash 等别名。
- 总资产缺记录时显示"现金+持仓成本估算（非实时市值）"，不冒充实时市值。
- 中文名称输入增加 IME 组合输入保护（compositionstart/end + isComposing），组合期间不触发整页 render。
