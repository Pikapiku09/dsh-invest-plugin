## 四、铁律自检（逐条打勾）

- [ ] 每笔单进场前都挂好了止损单
- [ ] 所有止损都机械执行了（无"再等等"）
- [ ] 单票仓位从未超过 25%
- [ ] 同板块合计从未超过 40%
- [ ] 没有向下补仓（摊薄成本）过
- [ ] 同一只票月交易次数 ≤ 3
- [ ] 没有连亏 3 笔还继续交易（停手规则）
- [ ] 没有追高 / 报复性交易
- [ ] 生活账户（包/车/应急金）一分没动
- [ ] 没有因为想挣钱而强迫自己交易
