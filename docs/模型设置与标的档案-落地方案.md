## 〇、现状诊断与数据流（先看这里）

### 0.1 后端「同源三处」约束（改后端必读）
`dsh-invest-plugin` 的 Host 逻辑存在**三处同源副本**，任何后端改动都必须保持一致：

| 文件 | 角色 | 生成方式 |
|---|---|---|
| `src/host.js` | **源码**（`invest_run` 工具 + `/api/dsh-invest/*` 路由 + agent 指引） | 手工维护 |
| `packages/dsh-invest/lib/index.js` | **常规插件运行体**（profile bundle 挂载，`/dsh-invest/api/*` 的实际处理方） | 手工维护，与 `src/host.js` 逻辑一致 |
| `dist/invest-run.host.js` | 动态插件形态（`cordis_define` 粘贴用） | `node tools/build.js` 由 `src/host.js` 自动生成 |

> 【实测·代码】`tools/build.js` 只把 `src/{prompts.js,lib/pure.js,lib/routes.js}` 转换进 `packages/dsh-invest/lib/{prompts,pure,routes}.js`，**不生成 `index.js`**；`index.js` 是与 `src/host.js` 平行的手工副本（CHANGELOG「已修 src/host.js、packages/dsh-invest/lib/index.js、dist/invest-run.host.js 三处同源代码」）。
> **落地动作**：改逻辑时**同时改 `src/host.js` 与 `packages/dsh-invest/lib/index.js`**，再跑 `node tools/build.js` 重生 `dist/invest-run.host.js`。
> 【推断】可选优化：把公共逻辑抽到 `src/lib/` 共享模块由两处 import，消除手工双写（非本方案必需）。

## 二、模块一：模型设置（宿主模型展示 / 更改 / 一键任务回显）

### 2.1 后端：暴露真实宿主模型
**新增两个 helper（放 `modelSettingsPayload` 上方）：**

```js
// 会话宿主模型 = 当前会话根 Agent 的 provider/model（executeJob 里继承的就是它）
const resolveSessionHostModel = () => {
  try {
    const agents = ctx.get("agents")
    const roots = agents && typeof agents.roots === "function" ? agents.roots() : []
    const host = roots[roots.length - 1]
    const opt = (host && host.options) ? host.options : {}
    const model = opt.model
    if (!model) return null
    const provider = opt.provider || ""
    return { provider, model, label: (provider ? provider + "/" : "") + model, source: "session" }
  } catch (e) { return null }
}
// 生效宿主模型 = 用户在「模型设置」选的覆盖（settings.defaultModel）优先，否则会话模型
const resolveHostModel = async () => {
  const settings = await readJsonFile(SETTINGS_FILE, {})
  const override = (typeof settings.defaultModel === "string" && settings.defaultModel.trim()) ? settings.defaultModel.trim() : ""
  if (override) {
    const slash = override.indexOf("/")
    return { provider: slash > 0 ? override.slice(0, slash) : "", model: slash > 0 ? override.slice(slash + 1) : override, label: override, source: "override" }
  }
  const session = resolveSessionHostModel()
  return session ? { ...session, source: "session" } : null
}
```

**`modelSettingsPayload()` 返回体追加两字段**（index.js:677 的 `return {...}`）：
```js

```

### 2.3 后端：让「继承宿主」真正落到所选宿主模型
`executeJob`（index.js:822-826）当前是 `agentOptions = hostAgent.options`。改为**优先 `resolveHostModel()`**：

### 3.1 高亮触发提醒的标的选项卡
**判定来源**：`state.watchlist.alerts`（`WatchAlert{code,kind,level,message,key,read,ts}`，types.ts:262）。命中 `kind ∈ {buy,stop,target,add,trim}` 且 `!read`（或当日活跃）即高亮。

function alertForCode(alerts: WatchAlert[], code: string): WatchAlert | undefined {
  const hit = alerts.find((a) => a.code === code && !a.read && ['buy','stop','target','add','trim'].includes(a.kind));
  return hit;
}
const KIND_LABEL: Record<string,string> = { buy:'买入', stop:'止损', target:'止盈', add:'加仓', trim:'减仓', invalidate:'失效' };

### 3.2 触发通知 → Windows 通知（主动推送）
**新增 `.dsh-invest/web/src/notify.ts`**：
```ts
const NOTIFY_KEY = 'dsh-invest.notifyEnabled';
const SEEN_KEY = 'dsh-invest.seenAlertKeys';

export function notifyEnabled(): boolean {
  try { return window.localStorage.getItem(NOTIFY_KEY) !== '0'; } catch { return true; }
}
export function setNotifyEnabled(on: boolean): void {
  try { window.localStorage.setItem(NOTIFY_KEY, on ? '1' : '0'); } catch {}
}
export async function ensureNotifyPermission(): Promise<NotificationPermission> {
  if (typeof Notification === 'undefined') return 'denied';
  if (Notification.permission === 'default') {
    try { return await Notification.requestPermission(); } catch { return Notification.permission; }
  }
  return Notification.permission;
}
function seen(): Set<string> {
  try { return new Set(JSON.parse(window.localStorage.getItem(SEEN_KEY) || '[]')); } catch { return new Set(); }
}
function markSeen(keys: string[]): void {
  const s = seen(); keys.forEach((k) => s.add(k));
  try { window.localStorage.setItem(SEEN_KEY, JSON.stringify([...s].slice(-500))); } catch {}
}
/** 派发一批新提醒到 Windows 通知（去重 + 权限 + toast 兜底） */
export async function pushAlertsToSystem(alerts: {key:string; title:string; body:string}[]): Promise<void> {
  const fresh = alerts.filter((a) => a.key && !seen().has(a.key));
  if (!fresh.length || !notifyEnabled()) return;
  const perm = await ensureNotifyPermission();
  for (const a of fresh) {
    if (perm === 'granted' && typeof Notification !== 'undefined') {
      try { new Notification(a.title, { body: a.body, tag: a.key, icon: undefined }); } catch {}
    }
    // 页面内 toast 兜底，保证「更明显」
    window.dispatchEvent(new CustomEvent('dsh-invest:system-notify', { detail: a }));
  }
  markSeen(fresh.map((a) => a.key));
}
```
> 【推断】`127.0.0.1`（localhost）是 secure context，Chrome/Edge 在 Windows 授权后 `new Notification()` 会弹 **Windows 通知**（Action Center）。页面内再派发一个 `CustomEvent` 让 `main.ts` 同步弹 `toast`，双保险更明显。
> 【待核实】若需「浏览器标签页关闭后仍弹系统通知」，需另做托盘/后端 BurntToast 脚本（超出 web 端范围，列为后续增强）。

**main.ts 接线**：在 `loadWatchlist()`/`refreshWatchlist()`/`syncAfterJobDone()` 拿到 alerts 后调用派发：
```ts
function dispatchAlertNotifications(alerts: WatchAlert[]): void {
  void pushAlertsToSystem(alerts.filter((a) => !a.read).map((a) => ({
    key: a.key, title: `${KIND_LABEL[a.kind] || a.kind}提醒 · ${a.name || a.code}`,
    body: a.message,
  })));
}
```
`main.ts` 监听 `dsh-invest:system-notify` 调用 `toast(detail.body, tone)`。模型设置页加「启用 Windows 通知」开关（`data-action="toggle-notify"`）控制 `setNotifyEnabled`。

### 3.3 止盈 / 止损 / 买入提醒标注「购买仓位数」
**语义**（【推断】）：
- **买入类**（`buy`）→ 计划买入股数 `watch.buy_qty`（新增字段，编辑表单可填）；
- **止盈/止损/加仓/减仓**（`target/stop/add/trim`，均属持有态）→ 持仓股数 `position.shares`。

**后端 `evalWatchSignal`（index.js:309）改造**：签名与 message 里嵌入仓位数，并给 `sig` 加 `qty`：
```js
const evalWatchSignal = (it) => {
  const m = it.monitor || {}, w = it.watch || {}, pos = it.position || {}
  const p = wNum(m.current_price)
  if (p === null || m.notify === false) return null
  const nm = it.name || it.code
  const f2 = (v) => v === null ? "—" : String(v)
  const buyQty = wNum(w.buy_qty)
  const heldQty = wNum(pos.shares)
  if (it.state === "观察") {
    const lo = wNum(w.buy_low), hi = wNum(w.buy_high)
    if (lo !== null && hi !== null && p >= lo && p <= hi) {
      return { key: it.code + "|buy|" + localYmd(), kind: "buy", level: "good", qty: buyQty,
        message: "【买入提醒】" + nm + " " + it.code + " 现价 " + p + " 落入买入区间 [" + lo + ", " + hi + "]，理想买点 " + f2(wNum(w.ideal_buy))
               + "，购买仓位数 " + (buyQty === null ? "待定" : buyQty + " 股") + "。" }
    }
    const inv = wNum(w.stop)
    if (inv !== null && p < inv) {
      return { key: it.code + "|invalidate|" + localYmd(), kind: "invalidate", level: "warn", qty: buyQty,
        message: "【观察失效】" + nm + " " + it.code + " 现价 " + p + " 跌破失效价 " + inv + "，观察逻辑：" + String(w.invalidate_if || "未填").slice(0, 60)
               + "，购买仓位数 " + (buyQty === null ? "待定" : buyQty + " 股") + "。" }
    }
    return null
  }
  if (it.state === "持有") {
    const held = heldQty === null ? "—" : heldQty + " 股"
    const st = wNum(pos.stop)
    if (st !== null && p <= st) return { key: it.code + "|stop|" + localYmd(), kind: "stop", level: "bad", qty: heldQty,
      message: "【止损提醒】" + nm + " " + it.code + " 现价 " + p + " 触及/跌破止损价 " + st + "，成本 " + f2(wNum(pos.cost)) + "，购买仓位数 " + held + "。" }
    const tg = wNum(pos.target)
    if (tg !== null && p >= tg) return { key: it.code + "|target|" + localYmd(), kind: "target", level: "good", qty: heldQty,
      message: "【止盈提醒】" + nm + " " + it.code + " 现价 " + p + " 达到目标价 " + tg + "，成本 " + f2(wNum(pos.cost)) + "，购买仓位数 " + held + "。" }
    const al = wNum(pos.add_low), ah = wNum(pos.add_high)
    if (al !== null && ah !== null && p >= al && p <= ah) return { key: it.code + "|add|" + localYmd(), kind: "add", level: "info", qty: heldQty,
      message: "【加仓提醒】" + nm + " " + it.code + " 现价 " + p + " 回落至加仓区间 [" + al + ", " + ah + "]，当前持仓 " + held + "。" }
    const tr = wNum(pos.trim_line)
    if (tr !== null && p >= tr) return { key: it.code + "|trim|" + localYmd(), kind: "trim", level: "warn", qty: heldQty,
      message: "【减仓提醒】" + nm + " " + it.code + " 现价 " + p + " 触及减仓线 " + tr + "，当前持仓 " + held + "。" }
    return null
  }
  return null
}
```

### 3.4 持仓工作区修改 → 标的档案同步
**根因**：持仓数/成本存在**两个源**——`持仓.json`（holdingPanel 读 `state.holdings`）与 `watchlist.position`（monitorPanel 读 `it.position`）。改持仓只写前者，后者失同步。

**后端 `confirmHoldingsDraft`（index.js:512）末尾（写完 `HOLDINGS_FILE` 后）追加回写**：
```js
// 新增：持仓账本 → 标的档案同步（持有态标的的股数/成本/现价跟随账本）
const syncWatchlistFromHoldings = async (positions) => {
  const doc = await readWatchlist()
  const byCode = new Map((positions || []).map((p) => [String(p.code || "").toUpperCase(), p]))
  let changed = false
  for (const it of doc.items || []) {
    if (it.state !== "持有") continue
    const p = byCode.get(String(it.code || "").toUpperCase())
    if (!p) continue
    const pos = it.position || (it.position = {})
    const shares = numOrNull(p.shares), cost = numOrNull(p.cost), cp = numOrNull(p.current_price)
    if (shares !== null && pos.shares !== shares) { pos.shares = shares; changed = true }
    if (cost  !== null && pos.cost  !== cost ) { pos.cost  = cost ; changed = true }
    if (cp    !== null) { it.monitor.current_price = cp }
    deriveWatch(it)
  }
  if (changed) await writeWatchlist(doc)
  return changed
}
// confirmHoldingsDraft 内，writeJsonFile(HOLDINGS_FILE, next) 之后：
await syncWatchlistFromHoldings(positions)
```

**前端 `confirmHoldingsDraft`（main.ts:761）成功分支**：`await loadHoldings()` 改为
```ts
await Promise.all([loadHoldings(), loadWatchlist()]);   // 同步重载持仓 + 标的档案
```
并在 `navigate('archive')` 时若 `!state.watchlist` 则 `void loadWatchlist()`（已在 boot 加载，兜底）。
> 效果：在**持仓工作区**改股数/成本并确认后，**标的档案**的监控卡片「成本 / 股数」、侧栏距离、买入区间派生值立即一致。

### 4.1 防重入 + 成功提示（main.ts）
```ts
async function refreshAll(): Promise<void> {
  if (state.refreshing) return;              // 防重入：刷新中禁止再次触发
  state.refreshing = true;
  render();
  const jobs: Promise<void>[] = [loadIndex(), loadHoldings(), loadWatchlist()];
  if (state.view === 'tasks') jobs.push(loadTemplates(), loadJobs());
  if (state.view === 'model-settings') jobs.push(loadModelSettings());
  if (state.selectedCode) jobs.push(reloadArchiveConclusions(state.selectedCode));
  try {
    await Promise.all(jobs);
    const failure = state.indexError || state.holdingsError || state.watchlistError || state.jobsError || state.templatesError;
    if (failure) toast(`刷新完成，但部分数据异常：${failure}`, 'error');
    else toast(`数据刷新成功（${new Date().toLocaleTimeString('zh-CN', { hour12: false })}）。`, 'success');
  } catch (error) {
    toast(`刷新失败：${errorMessage(error)}`, 'error');
  } finally {
    state.refreshing = false;
    render();
  }
}
```

### 4.2 按钮「刷新中」+ 旋转器 + 禁用（main.ts）
新增 `syncRefreshButton()`，由 `render()` 调用（替换原先绑 `state.indexLoading` 的那行）：
```ts
function syncRefreshButton(): void {
  const button = document.getElementById('refreshButton') as HTMLButtonElement | null;
  if (!button) return;
  button.disabled = state.refreshing;
  button.classList.toggle('is-loading', state.refreshing);   // CSS：.refresh-button.is-loading .icon { animation: spin }
  button.setAttribute('aria-busy', state.refreshing ? 'true' : 'false');
  const label = document.getElementById('refreshLabel');
  if (label) label.textContent = state.refreshing ? '刷新中' : '刷新数据';
}
```
