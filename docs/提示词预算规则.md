# 提示词预算规则（v0.17.0 起）

## 现状（2026-09-26 测量）

| 角色 | 字数 | 预算 |
|---|---|---|
| P_SELECT | 4,735 | ≤8,000 |
| P_NEWS | 5,580 | ≤8,000 |
| P_DEEP | 5,868 | ≤8,000 |
| P_FINAL | 3,161 | ≤8,000 |

膨胀主因 = DATA_BASE(2,676) + 策略指令本体；KB 模块（PSY 565 + VERIFIED 635）仅占 ~10%，不是主因。

## 规则

1. 单角色硬限 **10,000 字**、警戒线 8,000（构建时 tools/check_prompt_budget.js 自动检查）
2. KB 模块单模块上限 **700 字**：新验证规则入库时若超限，必须压缩旧条目（1进1出）
3. 超警戒线的处理顺序：先删过时条目 → 再合并语义重复 → 最后才考虑压缩措辞
4. 每次新增 KB 后跑 node tools/build.js（自动输出预算检查）
