fix(backtest): 赔率统计不再把「观察」算进方向收益（v0.75.1）

## 问题
同一屏出现两个分母：「5 日命中率」按 n=33 算，「盈亏比 / 单笔期望」按 n=68 算。
观察类结论（当时 34 条）被当成看多，静默计入胜率、盈亏比与期望值。

## 根因
- 命中率用 `bullish || bearish` 判定，观察天然被排除；
- 聚合方向收益时只对 bearish 取反、"其余一律当看多"，观察因此混了进去；
- 注释写的是"观察不计"，代码没有做到，且没有测试守住。

## 改动
- 抽出模块级常量 BULLISH_STANCES / BEARISH_STANCES，命中率与赔率共用同一套口径
- 方向收益只累加这两类立场；观察与 `减仓/回避` 这类非标准取值一律不计
- 版本 0.75.0 -> 0.75.1，同步 CHANGELOG / README / whats-new

## 实测影响（n=33）
- 分母 68 -> 33，与命中率同源
- 盈亏比 0.87 -> 1.01
- 单笔期望 -1.08% -> +1.64%
- 样本仍小，仅作记录，不构成对流水线能力的评判

- node --check 通过；npm run compat 10/10；npm test 248/248
