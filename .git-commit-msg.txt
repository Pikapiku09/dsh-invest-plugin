refactor(v0.75.0): 宿主服务取值收敛到单点访问器

## 问题

插件原来有 46 处直接取宿主服务：fs 39、agents 4、llm 2、attachments 1，
另有 sandboxPolicy 2 处与 4 处带第二参数的候选探测。
若 DSH 改了服务名，就要在几十个地方挨个找，漏一个就是静默失效。

## 做法

全部收敛到一个模块级访问器：

    function hostService(ctx, name, ...rest) { return ctx.get(name, ...rest) }

改名只需改这一行。

## 三条设计约束（改这里之前先读）

1. 保留「用的时候现取」。宿主可能先挂插件、后注册服务；若在 apply 时取一次存起来，
   会永远拿到空值——那才是真会改坏。访问器只转发，不缓存。
2. 放在模块级并显式接收 ctx，不写成 apply 内的闭包。这样调用点无论在 apply 内部
   还是外部函数里都不会因作用域拿不到 ctx。
3. 原样透传多余参数。插件里有 ctx.get(n, true) / ctx.get(n, false) 这种候选探测写法，
   第二个参数是查询标志；吞掉它会让这段静默改变含义。

## 回归断言

compat-check 新增：除访问器内部那 1 处外，源码不得出现裸 ctx.get。
少了这条，以后新代码又会到处写 ctx.get("fs")，这次改造就白做了。
